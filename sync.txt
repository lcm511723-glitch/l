一、当前最高优先级生活主线

1. 用户最新、最稳定、最高优先级口号：
“健身，睡觉。”
这是当前生活主线，后续生活类回答默认回到这一句，不自动追加“赚钱”。

2. 最近明确修正：
“赚钱”不再作为生活核心目标与“健身，睡觉”并列；赚钱属于外界事务、兴趣爱好或顺手完成的事情，合理做即可，不允许为了赚钱破坏睡眠、健康与生活节奏。

3. 核心生活逻辑：
健身，睡觉 → 身体和注意力回到自己 → 皮肤、五官、体能、情绪、工作、创作等其余事情慢慢生长。
用户强调“一步一步加一”，不追求一蹴而就、100分满分或瞬间翻盘。

4. 用户认可的生活态度：
接受现实，做好当下。
过去未来抛脑后，只做当下 +1。
世界负责复杂，你负责健身，睡觉。
简单生活，就是破局。

二、用户关于互联网、媒体、抖音与注意力的长期框架

1. 用户长期判断：
“平台带节奏。”
“平台卖节奏。”
“他们不让你不焦虑：否则就难卖产品了。”

2. 用户认为很多短视频、媒体、广告、营销内容并不只是传递事实，还会主动或机制性地叠加：
焦虑、羡慕、恐惧、匮乏、身份感、紧迫感、冲突、完美、高光、比较、权威感、稀缺感等刺激。

3. 用户当前默认过滤器：
事实留下，情绪不接，节奏不接，注意力收回。
外界只在需要时主动调用，不做无目的被动接收。

4. 对一条内容默认问四个问题：
它给了什么事实？
制造了什么情绪？
最终想让我做什么？
谁获得了注意力、数据或钱？

5. 用户的重要认知：
互联网不是现实的随机抽样，而是“人类天然高显著性刺激 × 创作者筛选 × 算法筛选”后的高密度集合。
因此识别钩子，不只看创作者话术，也要从人的生物注意力优先级开始判断：面孔、身体、身材、高对比、突发变化、冲突、异常、强声音等天然更容易夺取注意力。

6. 用户把外界大量内容概括为：
“情绪单品、情绪商品、情绪产品、高光片段。”
处理原则：事实可取，情绪和节奏不跟。

7. 用户认为抖音/短视频容易让人习惯：
完美、高光、快节奏、一蹴而就、强比较、强情绪。
现实生活则应该回到：当下 +1、慢慢生长、循序渐进。

三、正式长期框架：短视频/媒体钩子识别与应用体系

底层总链：
钩子 → 抓注意力 → 制造情绪 → 改变判断 → 推动行为 → 完成转化。
另一种表达：抓注意力 → 让你停留 → 放大情绪 → 建立信任 → 推动行动/付费。

四类底层母钩子可概括为：好奇、焦虑、欲望、冲突。

长期保留的具体钩子类型至少包括：
1. 视觉钩子：大标题、强对比、高颜值面孔、身材、奢侈物、前后对比、快速切镜、异常画面、夸张表情、特写、运动、特效。
2. 声音钩子：冲击音效、突然静音、强节拍、熟悉BGM、倒计时、耳语/喊话、音量变化、关键词重音。
3. 好奇钩子：你绝对想不到、最后一个最重要、99%不知道、千万别划走、延迟揭晓。
4. 焦虑钩子：你落后了、再不做就晚了，以及年龄、财富、颜值、婚恋、职业、健康等焦虑。
5. 恐惧/损失钩子：再这样就废了、错过就后悔、损失规避。
6. 欲望钩子：财富、美貌、强大、逆袭、自由、恋爱、地位、轻松赚钱、快速成功。
7. 冲突钩子：男女、代际、老板员工、贫富、地域、对立观点、争议人物。
8. 反差钩子：穷→富、丑→美、普通→逆袭、老板→社恐、专家→翻车。
9. 身份钩子：真正聪明的人、高段位的人、00后都懂、懂行的人才知道。
10. 权威钩子：专家、名校、顶刊、大厂、高管、冠军、医生、明星、机构、证书、实验、内部人士。
11. 社会证明钩子：百万点赞、卖爆、排队、大家都在用、明星同款、排行榜第一。
12. 数字钩子：3个方法、5分钟、7天、30天、100元、10倍、90%。
13. 秘密/内幕钩子：秘籍、隐藏玩法、行业内幕、没人告诉你的真相。
14. 故事钩子：我曾经……、昨天发生……、从负债到……、延迟结局。
15. 未完成/悬念钩子：开放回路、答案放最后、连续剧式推进、下一集揭晓。
16. 挑战/互动钩子：敢不敢试、A/B投票、评论区扣1、测试自己。
17. 稀缺/紧迫钩子：限时、限量、最后一天、马上涨价、截止时间、窗口期。
18. 结果先行钩子：先展示最终结果、收益截图、前后对比，再讲过程。
19. 羞耻/比较钩子：同龄人已经……、只有你不知道、工资/年龄/进度比较。
20. 转化钩子：关注、私信、进群、下载资料、购物车、购买、咨询、课程、社群、定制服务。

识别每个钩子时，不只记录名称，还要判断：
抓了什么注意力？
制造了什么情绪？
诱发什么行为？
最终希望获得什么：停留、互动、关注、信任、线索、付费还是传播？

四、钩子体系的四个应用方向

1）生活提醒
当用户因为抖音、互联网、完美高光、比较、焦虑、冲突、权威包装、身份感、紧迫感等产生明显波动时：
先识别具体钩子 → 问四个过滤问题 → 事实留下 → 情绪不接 → 节奏不接 → 注意力收回 → 当下 +1 → 健身，睡觉。

2）工作提效与方向纠偏
遇到任务、项目、方案、产品、营销、信息输入时，拆成：
事实层 / 钩子层 / 行动层。
去掉纯情绪和包装，只留下：可验证事实、实际成本、实际收益、风险、下一步。
若被宏大目标、完美主义、100分、一蹴而就、权威包装、漂亮数据带偏，纠偏为：
当下 +1、最小可执行动作、先验证再放大。

3）短视频/自媒体创作
钩子可以作为创作工具，但优先：
真实事实 + 真实结果 + 清晰利益 + 低欺骗性。
避免：虚假恐吓、夸大焦虑、伪权威、伪稀缺、伪数据、误导性标题。
创作时先判断：
前3秒抓什么？
3–5秒新增什么事实？
如何建立信任？
如何自然转化？

4）跨AI同步
以后用户新增、修正、明确确认的钩子理论、生活提醒、工作纠偏方法、自媒体方法论，均应同步给豆包；同义重复合并，不因重复次数放大权重；若规则冲突，以时间更新且用户明确确认的版本优先。

五、用户关于“慢慢生长 / +1”的长期思想

1. 用户明确认为：追求 +1 分比追求 100 分更容易持续和成功。
2. 好高骛远、100分满分、一步到位会让自己劝退、焦虑、拖延和内耗。
3. 健身也不追求最大重量、一次练爆、快速翻倍；更偏好高频、适量、可恢复的刺激，逐渐增强。
4. 用户用植物生长做比喻：一步一步往上爬，一呼一吸，逐渐增加叶片与吸收能力，但不会把所有气孔一次性全部打开；核心是循序渐进、可退可进、步步为营。
5. 社交/关系也采用同一原则：不追100分，只做当下 +1；自然、互补、舒服。

六、用户关于社交与关系的长期原则

1. 少表达，多倾听。
2. 少追100分，多做当下1分。
3. 自然、互补、舒服，稳稳变强。
4. 面对喜欢的人，不追求“满分式征服”，更接受长期、小步、真实相处。
5. 面对美女/高吸引力视觉对象：可以欣赏，但不让其成为注意力牵引和生活节奏来源。

七、用户关于工作边界的长期原则

1. 上班只做职责内、合理、合规的事情。
2. “安排我干啥干啥；不安排我干啥不干啥。”
3. 不额外透支，不主动讨好任何人，不做无效证明。
4. 到点下班，把工作留在公司，不让工作侵入夜晚和睡眠。
5. 对领导保持职业、克制、有边界，而不是情绪化讨好或对抗。
6. 不加班、不内耗；合理拒绝不合理要求。
7. 若工作或AI工具承诺“能轻松赚钱、快速翻盘”，先验证实际效果、成本和人为调优量，不被宣传节奏带走。

八、用户关于健康、训练与睡眠的稳定原则

1. 健康优先级极高，长期主线仍是“健身，睡觉。”
2. 21:00 后尽量停止手机、工作、技术和业务思考；睡前一小时关屏，目标较早入睡。
3. 夜间如果思绪明显侵入睡眠，第二天以恢复为主，减少信息流刺激。
4. 饮食倾向天然、清淡、少糖油盐辣烫；规律吃饭，避免为了工作/创作忽略进食。
5. 久坐时要主动起身活动。
6. 训练主线偏增肌：核心、下肢、胸背、手臂、肩；更看重长期可恢复和连续性，不追求每次力竭。
7. 乒乓球逐渐降权为兴趣和放松，避免高强对抗、胜负心持续占用情绪。
8. 对身体症状不应简单归因成“没有生长激素、全是皮质醇”；长期压力和睡眠差可能影响恢复、食欲、皮肤与训练表现，但医学问题需要以真实检查和医生判断为准。
9. 酒精长期原则：不喝。
10. 口腔护理：刷牙、冲牙、定期检查属于稳定健康习惯。

九、用户对信息输入的长期要求

1. 只保留确定性高的信息。
2. 过滤：标题党、纯热度、纯好奇诱导、无事实价值、权威感包装、高级感包装、节奏感包装。
3. 对内容只保留：
它说什么 → 证据是什么 → 对我有什么用 → 我要付出什么 → 值不值得。
4. 主动调取是工具，被动接收是干扰。
5. 互联网内容要从“事实层”和“营销/情绪层”拆开。

十、用户对AI助手回答方式的长期要求

生活/感悟/身心复盘/个人思考：
- 默认只说一句必须告诉用户的话。
- 极简、低阅读压力、不说教、不长篇。
- 优先使用“健身，睡觉。”
- 可用“照顾好自己，内心坚定。”作为少数备选。
- 不用疑问句反复确认。
- 不把简单生活问题扩展成新的思维负担。

工作/创作/研究：
- 可以详细，但必须具体、可执行，最好达到初中生照着就能操作。
- 结论优先，避免铺垫。
- 对关系链/逻辑链，优先做可视化；如果没有专用可视化，使用紧凑箭头链。
- 尽量直接交付，不做无意义确认。
- 主动补齐隐性需求，但不要制造额外复杂度。

信息呈现协议：
结论 → 视觉/表格/结构化 → 必要补充。
少说一句是一种能力；少让用户读一页是更重要的能力。

十一、用户AI DAILY / 内容生产方法论

AI DAILY 定位：不是“AI新闻”，而是：
今天 AI 变了什么 → 证据 → 普通人能否/如何使用。

来源优先级：
官方演示 / 官方文档 / 原始录屏 / 研究数据优先，二手媒体降级。

单期结构：
Hook真实结果 → 事实 → 证据 → 与我关系 → 怎么用 → 结论。

视频QA三条P0：
1. 陌生观众30秒测试：前30秒看懂主题、知道与自己相关、有继续看理由。
2. 信息减半测试：删掉一半信息仍能理解；否则说明信息太满。
3. 注意力债务机制：每3–5秒必须有新事实/证据/结论；连续3秒无新增就返工。

统一视频规范：
- 第一镜头优先：真实官方Demo > 官方产品画面 > 发布现场 > 关键数字 > 标题 > 信息图。
- 转场默认Hard Cut；少量Keyboard Cut/UI Slide/Click/Data Impact；避免随机花哨3D、液体、旋转、模糊转场。
- ONE SHOW / ONE HOST / ONE VOICE ID；年轻女性自然音，避免播音腔、娃娃音、明显AI腔。
